== Overview

It is 02:14. Morgan pages Sarah. Anomaly detection flagged irregular egress from a `payment-gateway` namespace on the production cluster. Morgan's instruction is to leave the pod running. Restarting it would drop the in-memory evidence. The first questions are who opened the shell, and how to cut off the egress without destroying that evidence.

image::fsi-security/sarah-call.png[Incident call,link=self, window=blank, width=100%]

== Your mission

Find the exec in the API audit log, confirm the external connection in RHACS, apply a deny-egress NetworkPolicy, and collect audit logs with `must-gather`.

Use the *Terminal* tab for the commands below.

.On each master node, search kube-apiserver/audit.log for namespace payment-gateway-{workshop_user_suffix}, objectRef.name payment-gateway, verb create, and subresource exec. Expect user.username system:serviceaccount:payment-gateway-{workshop_user_suffix}:cicd-pipeline-runner-sa, responseStatus.code 101, an exec into container httpd, and annotations naming the RoleBinding
[%collapsible]
====
[source,bash,subs="+macros,+attributes",role=execute]
----
namespace=payment-gateway-{workshop_user_suffix}

for master in $(oc get nodes --selector node-role.kubernetes.io/master --output name); do
  echo "=== Searching logs on ${master} ==="
  oc adm node-logs "${master}" --path=kube-apiserver/audit.log \
    | jq --arg ns "${namespace}" 'first(select(.objectRef.namespace == $ns
          and .objectRef.name == "payment-gateway"
          and .verb == "create"
          and .objectRef.subresource == "exec"))'
done
----
====

.In RHACS Network Graph, filter namespace payment-gateway-{workshop_user_suffix} and deployment payment-gateway, then open External Entities and find 185.199.108.153. Sign in with the RHACS username and password on the home page
[%collapsible]
====
. In RHACS, open *Network Graph*.
. Filter to namespace `payment-gateway-{workshop_user_suffix}` and deployment `payment-gateway`.
. Open *External Entities* and find the connection to `185.199.108.153`.

Sign in with the RHACS username and password on the xref:ROOT:index.adoc[home page].
====

.Apply NetworkPolicy payment-gateway-deny-egress in payment-gateway-{workshop_user_suffix} selecting app=payment-gateway, policyTypes Egress, and an empty egress list. Expect the external connection to drop while the pod stays up
[%collapsible]
====
[source,bash,subs="+macros,+attributes",role=execute]
----
oc apply -f - <<EOF
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: payment-gateway-deny-egress
  namespace: payment-gateway-{workshop_user_suffix}
spec:
  podSelector:
    matchLabels:
      app: payment-gateway
  policyTypes:
    - Egress
  egress: []
EOF
----

image::fsi-security/apply-networkpolicy.png[Deny egress NetworkPolicy,link=self, window=blank, width=100%]
====

.Collect audit logs with oc adm must-gather in namespace payment-gateway-{workshop_user_suffix} into /tmp/incident-artifacts using /usr/bin/gather_audit_logs, then find directories named audit_logs
[%collapsible]
====
[source,bash,subs="+macros,+attributes",role=execute]
----
oc adm must-gather \
  --run-namespace=payment-gateway-{workshop_user_suffix} \
  --dest-dir=/tmp/incident-artifacts \
  -- /usr/bin/gather_audit_logs
find /tmp/incident-artifacts -type d -name 'audit_logs' -print
----

image::fsi-security/sarah-support.png[Preparing audit logs for support,link=self, window=blank, width=100%]
====

== What you learned

* API audit attributes an exec to a service account, not just a pod name.
* A deny-egress NetworkPolicy contains the workload without deleting the process you still need to inspect.
* `oc adm must-gather` packages audit logs so someone else can review them.
